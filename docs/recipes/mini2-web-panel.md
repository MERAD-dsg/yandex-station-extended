# Локальная панель Станции Мини 2

Экспериментальная web-панель открывается по `http://<IP-колонки>/` и работает через Entware
`lighttpd` с CGI-обработчиком. Доступны статус, версия Quasar, память, нагрузка CPU, температура SoC,
занятое место в `/data`, громкость и ручная проверка цвета LED-зоны. Это не универсальный root-терминал:
пакеты, OTA, shell-команды, перезагрузка и рестарт Quasar из браузера **не** доступны.

## Установка

Нужен root SSH на порту 2222 и установленный YSE/Entware. Установщик поставит `lighttpd` и
модули авторизации/CGI. Из корня клона репозитория выполните на компьютере:

В Windows CMD из корня репозитория передайте каталог через SSH-архив (на прошивке нет `scp` и
SFTP-сервера):

```bat
tar -cf "%TEMP%\mini2-web-panel.tar" -C contrib mini2-web-panel
ssh -p 2222 root@192.168.1.4 "busybox mkdir -p /data/opt && busybox tar -xf - -C /data/opt" < "%TEMP%\mini2-web-panel.tar"
ssh -t -p 2222 root@192.168.1.4 sh /data/opt/mini2-web-panel/install.sh
```

Замените IP колонки. Последняя команда с `-t` нужна для интерактивного ввода пароля. Установщик через `yse` поставит
`lighttpd` и auth/CGI-модули, создаст парольный файл и CSRF-токен в `/data/opt/mini2-web-panel`,
добавит `/etc/init.d/S99zwebpanel` в автозапуск и запустит сервер. Пароль хранится в текстовом
файле с правами `600` (только root). Rootfs перемонтируется в RW лишь на время установки init-скрипта,
затем возвращается в RO.

Откройте `http://<IP-колонки>/`, войдите как `admin` с заданным паролем. Порт TCP 80 должен быть
свободен. Проверка/управление службой по SSH:

```sh
/etc/init.d/S99zwebpanel status
/etc/init.d/S99zwebpanel restart
sh /data/opt/mini2-web-panel/uninstall.sh
```

Удаление службы оставляет файлы панели и парольный файл в `/data/opt`; при желании удалите их отдельно.

## Безопасность

Панель защищена Basic Auth и CSRF-токеном; CGI принимает только перечисленные действия. Но HTTP
не шифрует пароль. Используйте только доверенную домашнюю сеть; не подключайтесь через публичный
Wi-Fi, не пробрасывайте TCP 80 на роутере и не публикуйте страницу в Интернет. CGI имеет root-права.

## Rainbow в режиме простоя

Прямой цикл записи в sysfs будет конкурировать со штатными индикациями Quasar. Idle-only rainbow пока
не включается автоматически. Чтобы подобрать совместимый хук для конкретной прошивки Mini 2,
сначала посмотрите имена доступных паттернов:

```sh
find /system/vendor/quasar/ledpatterns -type f -name '*.led' -print | sort
```

Список можно прислать для анализа; сами файлы не меняйте без резервной копии.
