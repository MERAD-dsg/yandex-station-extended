# Локальная панель Станции Мини 2

Экспериментальная web-панель открывается по `http://<IP-колонки>/` и работает через BusyBox `httpd`
с CGI-обработчиком. В первом этапе доступны статус, громкость и ручная проверка цвета LED-зоны.
Это не универсальный root-терминал: пакеты, OTA, shell-команды, перезагрузка и рестарт Quasar из
браузера **не** доступны.

## Установка

Нужен root SSH на порту 2222; BusyBox прошивки должен содержать applet `httpd`. Из корня клона
репозитория выполните на компьютере:

```sh
scp -P 2222 -r contrib/mini2-web-panel root@192.168.1.4:/data/opt/
ssh -t -p 2222 root@192.168.1.4 sh /data/opt/mini2-web-panel/install.sh
```

Замените IP колонки. `-t` нужен, чтобы интерактивно задать пароль. Установщик проверит наличие
`httpd`, создаст парольную конфигурацию и CSRF-токен в `/data/opt/mini2-web-panel`, добавит
`/etc/init.d/S99zwebpanel` в автозапуск и запустит сервер. Он перемонтирует rootfs в RW только на
время установки и затем вернёт RO.

Откройте `http://<IP-колонки>/`, войдите как `admin` с заданным паролем. Порт TCP 80 должен быть
свободен. Проверка/управление службой по SSH:

```sh
/etc/init.d/S99zwebpanel status
/etc/init.d/S99zwebpanel restart
sh /data/opt/mini2-web-panel/uninstall.sh
```

Удаление службы оставляет файлы панели и хэш пароля в `/data/opt`; при желании удалите их отдельно.

## Безопасность

Панель защищена Basic Auth и CSRF-токеном; CGI принимает только перечисленные действия. Но HTTP
не шифрует пароль. Используйте только доверенную домашнюю сеть; не подключайтесь через публичный
Wi-Fi, не пробрасывайте TCP 80 на роутере и не публикуйте страницу в Интернет. CGI имеет root-права.

## Rainbow в режиме простоя

Прямой цикл записи в sysfs будет конкурировать со штатными индикациями Quasar. Idle-only rainbow пока
не включается автоматически. Чтобы подобрать совместимый хук для конкретной прошивки Mini 2,
сначала посмотрите имена доступных паттернов:

```sh
find /system/vendor/quasar/ledpatterns -type f -name '*.led' -print | sort
```

Список можно прислать для анализа; сами файлы не меняйте без резервной копии.
