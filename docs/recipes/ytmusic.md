# YouTube Music: экспериментальный веб-плеер

Небольшой локальный веб-плеер для root-доступной Станции: поиск выполняется через неофициальный
InnerTube API, а встроенный GStreamer колонки получает команду воспроизвести найденный аудиопоток.
Смартфон управляет плеером с веб-страницы. Это **не** Google Cast и не Spotify Connect.

Проект рассчитан на rooted Станцию Мини 2 и требует проверки на конкретной прошивке. Файлы — в
[`contrib/ytmusic-player/`](https://github.com/Marker284/yandex-station-extended/tree/main/contrib/ytmusic-player).

## Что умеет прототип

- искать публичные музыкальные результаты;
- запускать выбранный прямой аудиопоток на колонке и останавливать его;
- управлять с телефона/ПК из той же локальной сети.

Поддерживается необязательная авторизация через локальный экспорт cookies для потоков, требующих
входа; личная библиотека, голосовой поиск, очередь, пауза и подписанные `signatureCipher`-потоки
не реализованы. YouTube может изменить внутренний протокол, поэтому поиск или запуск музыки может
сломаться без предупреждения.

## Запуск в Windows

1. Убедитесь, что root SSH на колонке работает: `ssh -p 2222 root@<IP_колонки>`.
   При первом подключении подтвердите host key. Пароль в описанной конфигурации пустой — нажмите
   Enter. Не открывайте порт SSH в Интернет.
2. Установите Python 3.10+ и OpenSSH на ПК. В PowerShell из корня клона репозитория выполните:

   ```powershell
   cd contrib\ytmusic-player
   py -m venv .venv
   .\.venv\Scripts\python -m pip install -r requirements.txt
   $env:YTM_STATION_HOST = "192.168.1.4"  # замените на IP своей колонки
   # Необязательно: Netscape cookies.txt для входа; подробности и предупреждения — в README рядом с app.py
   $env:YTM_COOKIE_FILE = "$HOME\Downloads\cookies.txt"
   .\.venv\Scripts\python app.py
   ```

3. В консоли сервера найдите адрес `http://<IP_ПК>:8788/?key=...` и откройте его на телефоне,
   подключённом к той же Wi-Fi-сети.
4. Найдите композицию и нажмите ▶. Для остановки нажмите **Стоп**. Сервер на ПК должен
   работать всё время воспроизведения; остановка сервера сама по себе не останавливает уже
   запущенную команду на колонке.

Если Windows спросит о сетевом доступе, разрешите его только в профиле **частной сети**.
Не настраивайте проброс TCP 8788 в Интернет. Веб-страница защищена случайным ключом, однако
SSH root с пустым паролем безопасен только в доверенной LAN.

## Ограничения и замечания

- InnerTube — внутренний, неофициальный протокол YouTube. Автор внешнего проекта
  [InnerTube-API](https://github.com/MohammadKobirShah/InnerTube-API) не является Google;
  этот прототип использует пакет `innertube` из его экосистемы.
- Прямые аудиоссылки временные. Если InnerTube вернёт шифрованный URL, ограничение региона,
  авторизацию или другой формат, приложение покажет ошибку. Оно не обходит DRM, Premium,
  возрастные или региональные ограничения.
- Бесплатный тариф может содержать рекламу и ограничения воспроизведения. Прототип не обещает
  поведение официального приложения и не эмулирует Premium.
- Колонка должна сама иметь доступ в Интернет. Если звук не стартует, проверьте лог
  `/data/opt/ytmusic-player.log` через SSH.
- Это эксперимент, а не официальная интеграция. Используйте YouTube в соответствии с его
  условиями и учитывайте права авторов.
