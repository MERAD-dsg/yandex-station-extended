# YouTube Music → Яндекс Станция: локальный веб-плеер

Экспериментальный прототип для rooted-станций на Buildroot/quasar, проверяемая цель — Мини 2.
Смартфон/ПК открывает локальную страницу, ищет музыку через неофициальный InnerTube-протокол и
отправляет команду колонке по SSH. Источник аудио колонка забирает напрямую через встроенный
GStreamer (`maind --gst-launch`); приложение не скачивает и не сохраняет треки.

Это **не** Spotify Connect и не Google Cast: плеер не появится в официальном приложении YouTube
Music как устройство. Управление — через локальную веб-страницу (поиск, play, stop).

## Требования

- rooted Станция с SSH `root@<IP>` на порту **2222** и пустым паролем, как в инструкции проекта;
- колонка и компьютер в одной доверенной локальной сети; колонке нужен Интернет;
- Python 3.10+ и OpenSSH на компьютере; телефон с браузером в той же Wi-Fi-сети;
- при первом подключении предварительно принять host key колонки в Windows Terminal/CMD:
  `ssh -p 2222 root@192.168.1.4` (замените адрес; подтвердите fingerprint и нажмите Enter для пустого пароля).

## Запуск на Windows

Из корня клона репозитория:

```powershell
cd contrib\ytmusic-player
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
$env:YTM_STATION_HOST = "192.168.1.4"
# Необязательно: путь к локальному cookies.txt (Netscape format), если треки требуют аккаунт
$env:YTM_COOKIE_FILE = "$HOME\Downloads\cookies.txt"
.\.venv\Scripts\python app.py
```

Если нужен вход в YouTube Music: в браузере войдите на `music.youtube.com`, экспортируйте cookies
для YouTube в **Netscape cookies.txt** локальным cookie-exporter и укажите путь через
`YTM_COOKIE_FILE`. Нужен хотя бы один cookie `SAPISID`, `__Secure-1PAPISID` или
`__Secure-3PAPISID`; приложение само создаёт краткоживущий `SAPISIDHASH` заголовок. После
обновления cookies перезапустите сервер. Статус появится в панели.

Файл cookies — фактически пароль к аккаунту: не отправляйте его никому, не вставляйте в чат,
не публикуйте и не коммитьте. Файл `contrib/ytmusic-player/cookies.txt` уже добавлен в `.gitignore`,
но лучше хранить экспорт вне репозитория. Используйте только локальный экспортёр, которому
доверяете; после теста отзовите активные сессии Google, если считаете cookies раскрытыми.

В консоли появится ссылка вида `http://<IP-компьютера>:8788/?key=<секрет>`. Откройте именно её
на телефоне/ПК. Сервер должен оставаться запущенным всё время воспроизведения. Для остановки
нажмите Ctrl+C в окне сервера.

Если Windows Firewall спросит доступ, разрешите его только для **частных сетей**. При необходимости
создайте правило для TCP-порта 8788 только в профиле Private. Не настраивайте проброс этого порта
на роутере и не публикуйте страницу в Интернет. Веб-ключ защищает панель, но root SSH всё равно
должен быть доступен только в доверенной LAN.

## Ограничения и безопасность

- InnerTube — неофициальный внутренний протокол YouTube; Google его не гарантирует. Поиск,
  формат ответа и потоковая ссылка могут сломаться без предупреждения.
- Требуется прямой URL аудиоформата. Cookie-вход может помочь с некоторыми запросами, но
  подписанные `signatureCipher`, Premium-only, возрастные/региональные ограничения и некоторые
  защищённые форматы не обходятся. Ничего DRM-защищённого приложение не расшифровывает.
- YouTube Music Free может показывать рекламу и ограничивать функции. Прототип не эмулирует
  Premium и не гарантирует наличие рекламных вставок в выдаваемом InnerTube-потоке; соблюдайте
  условия YouTube и права правообладателей.
- Колонка подключается к Google самостоятельно, поэтому у неё должен быть рабочий Интернет/DNS.
  Компьютер также остаётся включённым: на нём работает веб-сервер и SSH-контроллер.
- Воспроизведение запускается отдельным `maind --gst-launch` и останавливается кнопкой «Стоп».
  Если прошивка или другая программа заняла аудиоустройство, звук может не стартовать; лог на
  колонке: `/data/opt/ytmusic-player.log`.

## Основа

Прототип использует Python-пакет [`innertube`](https://github.com/tombulled/innertube) и опирается
на endpoint/структуру, показанные в
[`MohammadKobirShah/InnerTube-API`](https://github.com/MohammadKobirShah/InnerTube-API). Это
независимая экспериментальная интеграция; авторы проектов и Google не связаны с репозиторием.
