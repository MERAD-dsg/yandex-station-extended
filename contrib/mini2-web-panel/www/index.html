Воспроизвести свой файл

Проверка…
Только MP3/WAV до 10 МиБ, один файл за раз; новая загрузка заменит предыдущую. Воспроизведение идёт через аудиодекодеры Quasar/GStreamer и ALSA. Требуется Python 3; автозапуска нет. Если формат/кодек не поддержан прошивкой, плеер сообщит об ошибке.

Радуга только в простое · ручной режим

Проверка…
Тест вручную включает кольцо только после явного состояния Алисы IDLE/NONE и трёх секунд с полностью погашенными 18 каналами. При активности Алисы, потере IPC или изменении LED-канала монитор уступает Quasar. Файлы .led не меняются; автозапуска нет. Требуется Python 3. Стабильная работа подтверждена на Mini 2; после обновления прошивки проверьте статусы. У sysfs остаётся короткое окно гонки записи.

Веб-панель · безопасный режим

Показывает телеметрию устройства; позволяет менять громкость, проверять LED-зоны, вручную тестировать радугу в простое и загружать только ограниченные MP3/WAV-файлы для воспроизведения. Установка пакетов, произвольная работа с файлами и управление системными процессами не открыты из браузера.
Доступ только по паролю в домашней сети. Не пробрасывайте порт панели в Интернет.
