# Локальная web-панель для Станции Мини 2 (первый этап)

Экспериментальная панель на Entware `lighttpd`, открывается как `http://<IP-колонки>/`.
Первый этап намеренно ограничен чтением состояния, громкостью ALSA и ручной проверкой RGB-зоны.
Он **не** предоставляет произвольные shell-команды, OTA, редактирование файлов, перезапуск Quasar
или перезагрузку.

## Установка

Нужны Мини 2 с root SSH на `:2222`, установленный YSE/Entware и доверенная домашняя Wi-Fi-сеть.
Установщик поставит `lighttpd` и модули `auth`, `authn_file`, `cgi` через YSE (пакеты занимают
место в `/opt`). Выполните команды на компьютере из корня клона репозитория:

В Windows CMD из корня репозитория передайте каталог через SSH-архив (на прошивке нет `scp` и
SFTP-сервера):

```bat
tar -cf "%TEMP%\mini2-web-panel.tar" -C contrib mini2-web-panel
ssh -p 2222 root@192.168.1.4 "busybox mkdir -p /data/opt && busybox tar -xf - -C /data/opt" < "%TEMP%\mini2-web-panel.tar"
ssh -t -p 2222 root@192.168.1.4 sh /data/opt/mini2-web-panel/install.sh
```

Замените IP колонки. Последняя команда откроет интерактивный запрос пароля. Во время установки
задайте пароль панели дважды (он не попадает в Git или чат).
Установщик создаёт файл авторизации `/data/opt/mini2-web-panel/users` с правами `600`, CSRF-токен,
конфигурацию `lighttpd` и автозапуск `/etc/init.d/S99zwebpanel`. Файл `users` хранит пароль в
текстовом виде и читается только root; rootfs на время добавления init-скрипта перемонтируется в RW,
затем возвращается в RO.

После сообщения `Installed` откройте `http://192.168.1.4/` (замените IP) и войдите как `admin` с
заданным паролем. Для запуска по голому IP нужен свободный **TCP/80**. Сервер привязывается ко всем
интерфейсам колонки.

## Защита

Basic Auth и CSRF-защита включены; пароль не вшит в исходники. Но HTTP не шифруется: используйте
только доверенную локальную сеть, не открывайте/не пробрасывайте TCP/80 в Интернет и не используйте
панель через публичный Wi-Fi. CGI работает с root-правами, поэтому действия ограничены allow-list.

Проверить сервис через SSH:

```sh
/etc/init.d/S99zwebpanel status
/etc/init.d/S99zwebpanel restart
/etc/init.d/S99zwebpanel stop
```

Остановить и удалить автозапуск (данные панели/пароль остаются в `/data/opt`):

```sh
sh /data/opt/mini2-web-panel/uninstall.sh
```

## Радужная подсветка

Автоматически устанавливать непрерывный `ring-mini2-rainbow.sh` как режим простоя панель пока не
будет: такой цикл напрямую пишет в sysfs и может затереть стандартные сигналы Алисы
(слушает/говорит/ошибка). Для настоящего idle-only режима нужно сначала посмотреть, какие `.led`
паттерны и состояния установлены именно на этой прошивке Mini 2:

```sh
find /system/vendor/quasar/ledpatterns -type f -name '*.led' -print | sort
```

Экспорт списка имён и его разбор безопасны; сами `.led` файлы не меняйте до резервного копирования.
