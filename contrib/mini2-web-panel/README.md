# Локальная web-панель для Станции Мини 2 (первый этап)

Экспериментальная панель на Entware `lighttpd`, открывается как `http://<IP-колонки>/`.
Доступны статус, версия Quasar, память, нагрузка CPU, температура SoC, заполнение `/data`, громкость
ALSA, ручная проверка RGB-зоны, загрузка MP3/WAV для воспроизведения и ручной тест idle rainbow. Панель **не** предоставляет произвольные shell-команды, OTA, произвольное
редактирование файлов, перезапуск Quasar или перезагрузку.

## Установка

Нужны Мини 2 с root SSH на `:2222`, установленный YSE/Entware и доверенная домашняя Wi-Fi-сеть.
Установщик поставит `lighttpd` и модули `auth`, `authn_file`, `cgi` через YSE (пакеты занимают
место в `/opt`). Выполните команды на компьютере из корня клона репозитория:

В Windows CMD из корня репозитория передайте каталог через SSH-архив (на прошивке нет `scp` и
SFTP-сервера):

```bat
tar -cf "%TEMP%\mini2-web-panel.tar" -C contrib mini2-web-panel
ssh -p 2222 root@192.168.1.4 "busybox mkdir -p /data/opt && busybox tar -xf - -C /data/opt" < "%TEMP%\mini2-web-panel.tar"
ssh -t -p 2222 root@192.168.1.4 sh /data/opt/mini2-web-panel/install.sh
```

Замените IP колонки. Последняя команда откроет интерактивный запрос пароля. Во время установки
задайте пароль панели дважды (он не попадает в Git или чат).
Установщик создаёт файл авторизации `/data/opt/mini2-web-panel/users` с правами `600`, CSRF-токен,
конфигурацию `lighttpd` и автозапуск `/etc/init.d/S99zwebpanel`. Файл `users` хранит пароль в
текстовом виде и читается только root; rootfs на время добавления init-скрипта перемонтируется в RW,
затем возвращается в RO.

После сообщения `Installed` откройте `http://192.168.1.4/` (замените IP) и войдите как `admin` с
заданным паролем. Для запуска по голому IP нужен свободный **TCP/80**. Сервер привязывается ко всем
интерфейсам колонки.

### Обновление существующей установки

Из Windows CMD в корне репозитория передайте текущий каталог и перезапустите сервер (замените IP):

```bat
tar -cf "%TEMP%\mini2-web-panel.tar" -C contrib mini2-web-panel
ssh -p 2222 root@192.168.1.4 "busybox tar -xf - -C /data/opt" < "%TEMP%\mini2-web-panel.tar"
ssh -t -p 2222 root@192.168.1.4 sh /data/opt/mini2-web-panel/install.sh
ssh -p 2222 root@192.168.1.4 /etc/init.d/S99zwebpanel restart
```

Если Python 3 не установлен, установите его отдельно командой `yse install python3` по SSH; панель
не устанавливает Python автоматически.

## Защита

Basic Auth и CSRF-защита включены; пароль не вшит в исходники. Но HTTP не шифруется: используйте
только доверенную локальную сеть, не открывайте/не пробрасывайте TCP/80 в Интернет и не используйте
панель через публичный Wi-Fi. CGI работает с root-правами, поэтому действия ограничены allow-list.

Проверить сервис через SSH:

```sh
/etc/init.d/S99zwebpanel status
/etc/init.d/S99zwebpanel restart
/etc/init.d/S99zwebpanel stop
```

Остановить и удалить автозапуск (данные панели/пароль остаются в `/data/opt`):

```sh
sh /data/opt/mini2-web-panel/uninstall.sh
```

## Радуга только в простое (ручное включение)

В панели есть отдельные кнопки ручного запуска и остановки. По умолчанию тест выключен; он **не**
добавляет автозапуск, не меняет штатные `.led` файлы и не устанавливает Python сам. Если Python 3
ещё не установлен, выполните из Windows CMD вручную:

```bat
ssh -p 2222 root@192.168.1.4 "yse install python3"
```

Замените IP колонки. Затем обновите панель: её статус должен показать, что тест доступен. Запуск
осуществляется только кнопкой «Запустить тест»; панель также отправляет CSRF-токен. Остановка —
кнопкой «Остановить» или при удалении панели. Статус можно проверить напрямую из Windows CMD:

```bat
ssh -p 2222 root@192.168.1.4 "python3 /data/opt/mini2-web-panel/idle-rainbow.py status"
```

Прототип требует одновременно свежего явного AliceState IDLE/NONE из Quasar IPC на
`127.0.0.1:9875` и непрерывно тёмных всех 18 RGB-каналов в течение 3 секунд. При активности Алисы,
неизвестном/потерянном IPC или изменении любого LED-канала он прекращает писать и уступает
штатному рендереру. При ручной остановке он гасит кадр только если все каналы всё ещё совпадают с
его последним кадром; чужие значения не перезаписывает.

Протокол и enum согласованы с Mini 2 реализацией [Spotiya](https://github.com/klockky/spotiya/blob/main/src/voice.rs); пользователь подтвердил стабильную работу на своей Mini 2. Порог ожидания здесь — 3 секунды. После обновления прошивки проверьте статусы заново. Sysfs не предоставляет lock, поэтому остаётся короткое окно гонки между проверкой LED и записью; при неожиданном поведении сразу нажмите «Остановить». Панель обслуживает
CGI с root-правами — оставляйте её только в доверенной домашней сети и не публикуйте TCP/80.

## Загрузка и воспроизведение файла

В карточке «Воспроизвести свой файл» можно выбрать один файл **MP3 или WAV размером до 10 МиБ**,
загрузить его, нажать «Воспроизвести», затем «Стоп». Новая загрузка заменяет прежнюю; кнопка
«Удалить файл» останавливает плеер и удаляет только этот загруженный трек. Файл хранится в закрытом
каталоге панели под `/data/opt` и не раздаётся как статическая страница. При удалении самой панели
воспроизведение останавливается, но каталог данных сохраняется — удалите трек кнопкой до uninstall,
если не хотите оставлять его на колонке.

Загрузка защищена теми же Basic Auth и CSRF, имеет серверный предел 10 МиБ и принимает только
распознанные сигнатуры MP3/WAV. Для обработки требуется вручную установленный Python 3; установка
через панель невозможна. Воспроизведение использует Quasar `maind --gst-launch` и ALSA, не меняет
системные файлы и не запускается после перезагрузки. Доступность декодера зависит от прошивки;
если аудиоустройство занято штатным звуком или кодек не поддержан, интерфейс покажет ошибку.
